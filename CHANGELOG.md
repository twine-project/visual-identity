# Changelog

All notable changes to the TWINE visual identity are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html):

- **Major** – a new or redesigned logo, or a change to the main colour palette.
- **Minor** – new assets, variants or templates.
- **Patch** – fixes to existing files and documentation.

## [1.0.0] – 2026-10-19

First official release of the TWINE visual identity.

### Added

- Brand guidelines 2026 by Manuela Fiori (`guidelines/twine-brand-guidelines-2026.pdf`).
- Logo overview sheet (`guidelines/twine-logo-sheet.pdf`).
- Logos in SVG and PNG: horizontal and vertical lockups (6 colour variants each) and logomark (4 colour variants).
- Logo sheet in EPS, CMYK, for print (`logos/eps/twine-logo-sheet-cmyk.eps`).
- PowerPoint presentation template v0.4 (`templates/twine-presentation-template-v0.4.potx`).
- Preview page on GitHub Pages.
- README, LICENSE and CHANGELOG.

### Changed

- Reorganised the files into `guidelines/`, `logos/` and `templates/`.
- Renamed every file to the pattern `twine-<layout>-<variant>.<ext>` (lowercase, no spaces).

### Fixed

- File names that did not match their content:
  - the vertical main logo was named *Main horizontal logo* (PNG) and *Horizontal logo* (SVG);
  - the horizontal black gradient and white lines SVGs were named as duplicates with a `(1)` suffix;
  - the EPS file was named `_rgb` although it is CMYK.
